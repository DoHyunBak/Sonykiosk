Create a complete high-fidelity Figma-style kiosk UI system for a Sony Alpha popup store experience.

Project title:
Sony A7 beginner kiosk UI/UX

Core concept:
“This level of performance at this level of weight?”
Sub slogan:
“딸깍, 기술이 곧 감성이다”

Goal:
Design a portrait kiosk interface for beginners who feel intimidated by camera weight, autofocus, and lens choice. The kiosk should explain why a camera is still needed, why Sony is a good beginner system, and which A7 model fits the user best. The experience must feel premium, clear, simple, and information-first, not like an ecommerce checkout flow.

Important design principles:
- portrait kiosk screen, 1080x1920
- screen UI only, no kiosk hardware mockup
- no human hands, no surrounding environment
- realistic tappable interface, not poster art
- information-first layout
- image-led design, minimal but clear Korean text
- premium Sony tone and manner
- modern, minimal, refined, clean spacing
- fixed left sidebar navigation visible on all main and sub pages
- sidebar items in Korean: 홈, 왜 카메라, 왜 소니, 라인업, AF, 렌즈, 추천
- strong visual hierarchy
- clear buttons, cards, tabs, chips, comparison modules
- dark premium palette: black, charcoal, white, subtle Sony blue accent
- no neon, no cyberpunk, no glassmorphism overload
- clean sans-serif Korean typography
- consistent margins, consistent card style, consistent icon style
- make the UI feel like a real popup store kiosk, not a phone app and not a dashboard

Target user:
beginner camera users in their 20s to 30s, interested in travel, daily life, portraits, vlog, and better results than smartphones, but afraid of heavy gear and difficult controls

Main message:
Sony helps beginners get better results with less failure through lightweight full-frame bodies, strong autofocus, and flexible lens ecosystem.

Create the following full screen flow:

1. Landing page
- large premium hero visual of a compact Sony full-frame camera and lifestyle photo
- headline in Korean: “이 정도 성능에 이 정도 무게?”
- sub headline in Korean: “딸깍, 기술이 곧 감성이다”
- short supportive text explaining easy entry for beginners
- primary button: “가볍게 시작하기”
- secondary button: “라인업 보기”
- strong first impression, premium and clean

2. Why camera page
- educational information page
- headline: “못 찍은 순간은 복구되지 않습니다”
- three visual comparison sections:
  1) low light
  2) motion capture
  3) zoom detail
- compare smartphone versus camera in a simple image-based way
- avoid technical jargon
- focus on result reliability, not specs
- bottom CTA button: “왜 소니인가”

3. Why Sony page
- persuasive information page
- headline: “결과를 쉽게 만드는 시스템”
- three key content blocks with icons and visuals:
  1) strong autofocus
  2) lightweight full-frame
  3) wide E-mount lens ecosystem
- beginner-friendly Korean copy only
- include one emotional but restrained lifestyle banner about capturing important moments confidently
- CTA button: “라인업 비교하기”

- this is the main page of the kiosk
- headline: “당신에게 맞는 A7을 고르세요”

  1) 가볍게 들고 다니기 좋음

- CTA buttons:
  - “상세 정보 보기”
  - “다른 모델 비교”

Global UI rules:
- every page must feel consistent
- left sidebar stays fixed
- use large clean cards and clear tap targets
- prioritize images, comparisons, and visual explanation over long paragraphs
- no poster layout, no decorative unused elements
- no tiny unreadable text
- no excessive specs
- no ecommerce cart, no checkout flow
- not a purchase kiosk, but an information and recommendation kiosk
- each page should clearly communicate one purpose
- maintain a premium Sony Alpha retail experience

Desired output:
- a cohesive multi-screen kiosk UI flow
- high-fidelity visual mockups
- realistic Korean interface components
- polished layout suitable for a university kiosk UI/UX presentation and Figma refinement
